# 语言失真 Language Distortion · 识别测试版

交互装置《语言失真》的检测页公开测试版：用你的摄像头和麦克风读取身体姿态、面部表情和语音语调，
实时显示三株植物（触手 / 机械花 / 气囊花）此刻会做出的反应。

- 只做识别，不连接实体植物（从非本机地址打开时自动进入测试模式）
- 需要 Chrome 或 Edge；首次打开会下载识别模型（语音情绪模型约 90MB）
- 按 D：显示 / 隐藏三株植物的反应读数；按 C：调试面板，手动拖滑块试各种状态

这个文件夹由 `bridge/make_public.sh` 从项目的 `web/` 生成，不要直接改这里的文件。
